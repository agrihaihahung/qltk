Sao lưu dữ liệu

Tải toàn bộ dữ liệu (kho, giao dịch, phiếu, báo giá, danh mục, khách hàng) về máy. Nên sao lưu hằng tuần và trước mỗi lần cập nhật web hoặc SQL. Cất file ở nơi an toàn (ổ ngoài, Google Drive riêng tư).

Cần khôi phục? Dùng mục Khôi phục dữ liệu ở sidebar để biến file sao lưu thành SQL.

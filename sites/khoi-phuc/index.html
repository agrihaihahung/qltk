Khôi phục dữ liệu từ file sao lưu

Chọn file .json đã sao lưu. Trang này tạo ra file SQL; bạn dán và chạy file đó trong Supabase → SQL Editor. File chỉ được đọc trên máy bạn, không gửi đi đâu.

Đang kiểm tra quyền…

Trước khi chạy SQL, hãy tải một bản sao lưu mới ở mục Sao lưu dữ liệu để có đường quay lại.

BảngSố dòng trong file

  1. Mở Supabase → SQL Editor → New query.
  2. Mở file .sql vừa tải bằng Notepad, chép toàn bộ nội dung, dán vào và bấm Run.
  3. Nếu tạo nhiều file: chạy lần lượt theo số thứ tự 01, 02, 03…
  4. Vào web, nhấn Ctrl+F5 và kiểm tra lại tồn kho, báo giá.
